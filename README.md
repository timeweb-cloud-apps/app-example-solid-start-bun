# solid-start on bun

Пример solid-start на bun для Timeweb Cloud Apps.

## Параметры деплоя

| Параметр | Значение |
| --- | --- |
| Runtime | `bun` |
| Фреймворк в API | `solid-start` |
| Тип приложения | `frontend` |
| Команда сборки | `bun run build` |
| Директория сборки | `.output/public` |

## Локальный запуск

```bash
bun install
bun run build
```
